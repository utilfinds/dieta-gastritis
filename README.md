# Dieta para gastritis y estreñimiento

App web (un solo archivo `index.html`) con menú diario, recetas, registro de agua, comidas y evacuaciones, y lista de compras. Los datos se guardan en el navegador (localStorage).

Ver en línea: https://utilfinds.github.io/dieta-gastritis/

> Orientación general; no sustituye la consulta médica.
